# Minecraft Server-Status & `server.properties` Generator

Ein kleines Web-Tool für die Einrichtung und Überprüfung von Minecraft-Servern.

- **Live-Anwendung:** [https://kiakademie.github.io/minecraft-server-config/](https://kiakademie.github.io/minecraft-server-config/)
- **Autor:** Joel Neto Romeira

## Funktionen

1. **`server.properties` Generator:** Wichtige Server-Einstellungen (Spielmodus, Schwierigkeitsgrad, maximale Spielerzahl, Sichtweite, Whitelist, Port) einfach auswählen und als fertige Konfigurationsdatei kopieren oder herunterladen.
2. **Server-Status-Abfrage (öffentliche API):** Fragt über die öffentliche Schnittstelle `https://api.mcsrvstat.us/3/<adresse>` ab, ob ein Minecraft-Server erreichbar ist, welche Version läuft und wie viele Spieler online sind.
